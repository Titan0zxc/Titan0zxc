## Учебные проекты

### Расписание учебных занятий

[Открыть проект](https://github.com/Titan0zxc/university-schedule-system)

Приложение для ведения расписания аудиторных занятий
и формирования отчётов.

В репозитории представлены:
- роли администратора, преподавателя и студента;
- концептуальная, логическая и физическая модели данных;
- материалы по нормализации и диаграмма IDEF0;
- SQL-скрипт, интерфейсы приложения и учебная документация.

**Технологии:** C#, Windows Forms, SQL Server, ADO.NET.

### Управление заказами предприятия

[Открыть проект](https://github.com/Titan0zxc/wood-production-management)

Учебная модель работы деревообрабатывающего предприятия:
заказы, задачи и взаимодействие участников процесса.

В репозитории представлены:
- модель заказа и отдельные интерфейсы участников;
- диаграммы вариантов использования и последовательности;
- модели потоков данных и процессов;
- программный прототип и учебная документация.

**Технологии:** C#, Windows Forms, файловое хранение данных.

### Медицинский регистратор

[Открыть проект](https://github.com/Titan0zxc/med_registrator)

Учебное приложение для обработки анкеты и формирования
результата по заданным правилам.

В репозитории представлены:
- последовательная обработка данных через цепочку фильтров;
- модель данных и хранение в SQLite;
- взаимодействие с локальным HTTP-сервисом проверки полиса;
- диаграммы PlantUML и описание сценариев.

Проверка полиса и правила обработки анкеты моделируются
в учебных целях.

**Технологии:** Java, JavaFX, SQLite, HTTP, Maven.
